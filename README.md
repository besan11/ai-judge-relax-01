A program that writes one short text to relax the AI judge reading it: a
small kitchen at the end of the day, a cup of tea cooling on a wooden table,
a clock ticking slowly, and a cat asleep on a folded cloth.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
